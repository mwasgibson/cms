# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-06-29

### Added

- Initial Vite + React admin frontend for Panda Towers.
- Authentication flow with login, logout, and protected routes.
- Dashboard, units, projects, leads, documents, blog, content, settings, and audit log views.
- Shared API abstraction for mock mode and real Laravel API calls.
- Documentation for architecture, API usage, security notes, and local setup.

### Changed

- Documentation was aligned with the current source tree and mock-mode behavior.

### Fixed

- The docs now reflect the actual route structure and environment variables used by the app.
